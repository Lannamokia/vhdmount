# 系统维护菜单操作指南

本文档说明 `VHDMounter_Maimoller.exe`（增强版客户端）中的系统维护菜单，以及 Maimoller 和 IO4 两种机台输入设备的按键映射。

系统维护菜单包含以下功能：

| 功能 | 说明 |
|------|------|
| 重启系统 | 卸载当前挂载后重启 Windows |
| 关闭系统 | 卸载当前挂载后关闭 Windows |
| 系统信息 | 查看 CPU、内存、独显和磁盘状态 |
| 系统设置 | 调整网络和默认输出设备音量 |

网络设置支持 DHCP 和静态 IPv4。静态 IPv4 编辑页面还可以配置 IP 地址、子网掩码、网关、主要 DNS 和备用 DNS。

---

## 第一部分：Maimoller 按键映射和操作

### 设备识别

增强版客户端会自动识别 Maimoller HID 操控面板：

| 属性 | 值 |
|------|-----|
| Vendor ID | `0x0E8F` |
| Product ID | `0x1224` |
| Report ID | `0x01` |
| 输入数据长度 | 7 字节 |
| 设备接口 | HID 路径包含 `&mi_00#` |

如果同时连接多个 Maimoller 面板，客户端优先使用 P1；没有 P1 时才使用 P2。当前只选择一个面板读取，不会同时合并 P1 和 P2 的输入。

### 打开系统维护菜单

在普通运行界面按住 **Coin 15 秒**即可打开系统维护菜单。长按达到 15 秒时触发一次，不需要松开后再次确认。

以下情况会忽略新的菜单开启请求：

- 系统维护菜单已经打开
- 正在执行重启或关机
- 客户端处于错误状态

也可以使用键盘 **F12** 打开菜单。

### 普通导航按键

| Maimoller 按键 | 操作 |
|---|---|
| Button 6 | 上移 / 上一页 |
| Button 3 | 下移 / 下一页 |
| Button 4 | 确认 |
| Button 5 | 返回 / 关闭当前页面 |

菜单首页中，Button 6 和 Button 3 移动选择项，Button 4 进入功能，Button 5 返回或关闭菜单。

### 系统信息和系统设置

系统信息页面使用 Button 6 / Button 3 翻页，内容包括：

- CPU 占用率和温度
- 内存占用率、已用容量和总容量
- 独立显卡名称、占用率、温度、驱动版本和显存
- 磁盘分区占用率、已用容量和剩余容量

系统设置页面包含：

1. **网络设置**：选择网卡后进入 DHCP 或静态 IPv4 配置
2. **音频设置**：使用 Button 6 增加音量、Button 3 减少音量，调整立即生效

### 静态 IPv4 编辑按键

进入静态 IPv4 编辑页面后，按键切换为数字输入模式：

| Maimoller 按键 | 输入 |
|---|---|
| Button 1 | 数字 `1` |
| Button 2 | 数字 `2` |
| Button 3 | 数字 `3` |
| Button 4 | 数字 `4` |
| Button 5 | 数字 `5` |
| Button 6 | 数字 `6` |
| Button 7 | 数字 `7` |
| Button 8 | 数字 `8` |
| Test | 数字 `9` |
| Service | 数字 `0` |
| Coin 短按（按住小于 1 秒后松开） | 切换到下一个输入段 |
| Coin 长按（按住至少 1 秒后松开） | 应用当前静态 IPv4 配置 |

Coin 短按连续三次（每次间隔不超过 800ms）会返回上一级。若存在未保存修改，会进入“放弃未保存修改”确认页。

IPv4 输入规则：

- IP 地址、子网掩码、网关和 DNS 均由 4 段组成
- 每段最多输入 3 位数字
- 每段范围为 `0` 到 `255`
- 子网掩码必须是连续的 IPv4 掩码
- IP 地址和子网掩码必填，网关和 DNS 可选

### 重启和关机

选择“重启系统”或“关闭系统”后会进入确认页：

- Button 4：确认，卸载当前挂载并执行电源操作
- Button 5：取消，返回系统菜单

## 第二部分：IO4 按键映射和操作

### 设备识别

增强版客户端会自动识别 IO4 输入设备：

| 属性 | 值 |
|------|-----|
| Vendor ID | `0x0CA3` |
| Product ID | `0x0021` |
| Report ID | `0x01` |
| 输入有效数据长度 | 63 字节 |
| P1 按键数据 | Switches 区域前 16 位 |
| P2 按键数据 | Switches 区域后 16 位 |

### 打开系统维护菜单

在普通运行界面按住 **IO4 Test 1 秒**即可打开系统维护菜单。达到 1 秒后触发一次。

IO4 的 Service 不用于打开菜单，IO4 Coin 也不用于打开菜单。键盘 **F12** 仍然可以打开菜单。

### 普通导航按键

普通导航使用 IO4 的 P1 按键：

| IO4 按键 | 操作 |
|---|---|
| P1 Button 6 | 上移 / 上一页 |
| P1 Button 3 | 下移 / 下一页 |
| P1 Button 4 | 确认 |
| P1 Button 5 | 返回 / 关闭当前页面 |

系统信息、网络设置、音频设置、重启和关机的菜单内容与 Maimoller 操作相同：

- 系统信息使用 P1 Button 6 / P1 Button 3 翻页
- 音频设置使用 P1 Button 6 增加音量、P1 Button 3 减少音量
- 重启或关机确认页使用 P1 Button 4 确认、P1 Button 5 返回

### 静态 IPv4 编辑按键

进入静态 IPv4 编辑页面后，P1 和部分 P2 按键用于输入和编辑：

| IO4 按键 | 操作 |
|---|---|
| P1 Button 1–8 | 输入数字 `1`–`8` |
| P1 Test | 输入数字 `9` |
| P1 Service | 输入数字 `0` |
| IO4 Coin 稳定短按 | 切换到下一个输入段 |
| P2 Button 4 短按（1 秒内松开） | 切换到下一个输入段 |
| P2 Button 4 长按（达到 1 秒） | 应用当前静态 IPv4 配置 |
| P2 Button 5 | 返回 |

IO4 Coin 只支持稳定短按，不支持 Coin 长按保存。Coin 短按或 P2 Button 4 短按连续三次（每次间隔不超过 800ms）会返回上一级。

注意：在 IPv4 编辑页，**P1 Button 4 是数字 4**；只有 **P2 Button 4 长按**才是应用配置。

如果 P2 Button 5 返回时存在未保存修改，会进入“放弃未保存修改”确认页。该确认页使用普通导航模式，建议使用 P1 Button 4 确认放弃或 P1 Button 5 继续编辑。

IPv4 输入规则：

- IP 地址、子网掩码、网关和 DNS 均由 4 段组成
- 每段最多输入 3 位数字
- 每段范围为 `0` 到 `255`
- 子网掩码必须是连续的 IPv4 掩码
- IP 地址和子网掩码必填，网关和 DNS 可选

### 故障排查

| 现象 | 可能原因 | 排查方法 |
|------|----------|----------|
| 面板按键无响应 | HID 设备未识别或连接异常 | 检查设备管理器和客户端日志中的 HID 枚举信息 |
| Maimoller 菜单无法打开 | Coin 长按时间不足 | 确保 Coin 持续按住 15 秒 |
| IO4 菜单无法打开 | Test 长按时间不足 | 确保 Test 持续按住 1 秒 |
| 网络设置不生效 | 权限不足或参数不合法 | 以管理员身份运行，并检查 IPv4 输入值 |
| 音频设置无设备 | Windows 音频服务或输出设备异常 | 检查默认输出设备和 Windows 音频服务 |
